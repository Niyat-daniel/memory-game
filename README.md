A simple and interactive Memory Game built using HTML, CSS, and JavaScript. The goal is to match all pairs of cards by remembering their positions and finding the matching cards.



Technologies Used

1. HTML5 — Creates the structure of the game
2. CSS3 — Handles styling, layout, animations, and responsiveness
3. JavaScript — Controls the game logic and card flipping

How to Play
1. Click on any card to reveal its symbol.
2. Click on another card to reveal its symbol.
3. If the two cards match, they remain visible.
4. If they don't match, they are flipped back.
5. Continue matching cards until all pairs are found.
6. Try to complete the game using as few moves as possible.
